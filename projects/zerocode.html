ZeroCode

Un agent de codage pour le terminal qui travaille dans le projet réel : il explore les fichiers, propose des modifications, lance des commandes et peut s’appuyer sur plusieurs fournisseurs de modèles.

Voir le dépôt GitHub ↗Installation ↓
Le problème

Passer du chat au travail concret.

Un assistant de programmation devient réellement utile lorsqu’il peut comprendre la structure d’un dépôt, lire des fichiers ciblés, proposer une modification, exécuter les tests et présenter le résultat. ZeroCode rassemble ces étapes dans une expérience terminale.

Fonctionnement

Un agent, plusieurs fournisseurs.

Une architecture modulaire sépare l’agent, le routeur, les clients compatibles avec l’API OpenAI, les outils de projet et la gestion des sessions. Le mécanisme de repli permet d’essayer d’autres fournisseurs lorsque le modèle sélectionné est indisponible ou limité.

Python · CLI et TUIStreaming et appels d’outilsSessions reprenablesCatalogue multi-fournisseurs
Sécurité

Des permissions visibles avant l’autonomie.

Les actions de lecture sont séparées des mutations. Les écritures et les commandes shell demandent une autorisation dans le mode normal, tandis que les chemins sont contrôlés et que les sorties de commande sont limitées. Le mode autonome reste plus risqué : il faut l’utiliser uniquement dans un dépôt de confiance et relire les changements.

Technologies

Un outil Python installable.

Le projet utilise Python 3.10 ou plus récent, un paquet déclaratif via pyproject.toml, une commande console zerocode et des dépendances explicites. Les tests automatisés et Ruff font partie du flux de développement documenté.

Les modèles et quotas gratuits dépendent de fournisseurs tiers et peuvent changer. ZeroCode n’inclut pas de garantie de gratuité permanente pour un modèle précis.

Installation

Prêt à l’essayer sur sa machine.

Prérequis : Python 3.10+ et Git. La publication du dépôt en accès public est nécessaire avant que ces commandes puissent fonctionner pour tout le monde.

Linux et macOS

python3 -m pip install --user pipx
python3 -m pipx ensurepath
pipx install git+https://github.com/hackerboy-223/zerocode.git
zerocode --version
zerocode doctor

Windows · PowerShell

py -m pip install --user pipx
py -m pipx ensurepath
pipx install git+https://github.com/hackerboy-223/zerocode.git
zerocode --version
zerocode doctor

Pour travailler depuis le code source ou contribuer :

git clone https://github.com/hackerboy-223/zerocode.git
cd zerocode
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell : .venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pytest
ruff check src tests

Après installation, lance zerocode setup pour configurer les fournisseurs, ou utilise un fournisseur anonyme disponible. Ne place jamais de clé API dans le dépôt. Les offres gratuites ont des limites et leurs conditions peuvent changer.

Résultat actuel

Un projet logiciel complet, pas seulement une maquette.

ZeroCode possède une architecture modulaire, des outils de fichiers et de shell, un routeur multi-fournisseurs, une interface terminale et une suite de tests. Les prochaines priorités sont de valider l’installation sur plusieurs systèmes, publier les versions et continuer le durcissement des permissions.
