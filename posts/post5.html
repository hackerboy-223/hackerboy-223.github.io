Introduction à JavaScript

JavaScript rend vos sites interactifs ! Découvrez ses bases, ses usages et des exemples concrets.

2025-01-20Par H@CKERBOY
Dans cet article

Lecture libre, sans jargon inutile.

Qu'est-ce que JavaScript ?

JavaScript est le langage de programmation du web. Il permet de créer du contenu dynamique et interactif : animations, formulaires intelligents, appels API et bien plus.

Variables et types de données

En JavaScript, vous pouvez déclarer des variables avec let ou const (préférez-les à var) :

const pseudo = "H@CKERBOY"; // String
let niveau = 99;            // Number
let isAdmin = true;         // Boolean

Fonctions

Les fonctions sont des blocs de code réutilisables qui exécutent une tâche spécifique :

function saluer(nom) {
  return `Salut ${nom} !`;
}

console.log(saluer("H@CKERBOY"));

Événements et DOM

JavaScript permet de réagir aux actions de l'utilisateur grâce aux événements :

document.querySelector('button')
  .addEventListener('click', function () {
    alert('Hello JS!');
  });

Conseils pour débuter

  • Bien commenter son code.
  • Tester dans la console du navigateur (F12).
  • Utiliser let et const plutôt que var.
  • Apprendre à lire les messages d'erreur : ce sont vos meilleurs alliés !
