Introduction au CSS

Le CSS permet de styliser vos pages web : couleurs, mise en page, animations... Découvrez ses bases et ses astuces !

2025-01-15Par H@CKERBOY
Dans cet article

Lecture libre, sans jargon inutile.

Qu'est-ce que le CSS ?

Le CSS (Cascading Style Sheets) est un langage de style utilisé pour décrire la présentation d'un document écrit en HTML.

Syntaxe de base

Une règle CSS se compose d'un sélecteur et d'un bloc de déclarations :

body {
  background: #222;
  color: #fff;
}

Sélecteurs courants

  • * : Sélecteur universel
  • element : Sélecteur d'élément
  • .class : Sélecteur de classe
  • #id : Sélecteur d'ID

Propriétés importantes

  • color : Couleur du texte
  • font-size : Taille de la police
  • background-color : Couleur de fond
  • margin : Marge extérieure
  • padding : Marge intérieure

Bonnes pratiques

  • Utiliser des classes pour réutiliser les styles.
  • Minifier le CSS en production pour de meilleures performances.
  • Tester sur différents navigateurs et tailles d'écran.
