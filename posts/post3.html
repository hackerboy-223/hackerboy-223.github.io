Qu'est-ce que le HTML ?

Le HTML (HyperText Markup Language) est le langage de base pour créer des pages web. Il utilise des balises pour structurer le contenu.

Structure de base

Une page HTML commence toujours par <!DOCTYPE html> et contient des éléments comme <head> et <body>.

Balises importantes

  • <h1> à <h6> : Titres
  • <p> : Paragraphes
  • <a> : Liens
  • <img> : Images
  • <div> : Conteneurs

Exemple minimal

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bonjour le monde !</h1>
  </body>
</html>

Bonnes pratiques

  • Utiliser des balises sémantiques (<header>, <main>, <footer>…).
  • Toujours renseigner l'attribut alt des images.
  • Valider son code avec le validateur du W3C.
