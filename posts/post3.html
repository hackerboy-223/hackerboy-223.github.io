Introduction au HTML : structure et balises essentielles

Apprendre les bases du HTML, les balises sémantiques et la structure d’une page web accessible et bien organisée.

2025-01-10Par H@CKERBOY
Dans cet article

Lecture libre, sans jargon inutile.

La structure minimale d’une page HTML

HTML décrit la structure et le sens d’une page. Une base correcte commence par une déclaration, un élément racine et deux zones principales : <head> pour les métadonnées et <body> pour le contenu visible.

<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bonjour le Web</h1>
    <p>Une page structurée est plus facile à lire et à maintenir.</p>
  </body>
</html>

Les balises qui donnent du sens

Une balise sémantique explique le rôle du contenu au navigateur, aux moteurs de recherche et aux technologies d’assistance. Utilise un titre pour un titre, un paragraphe pour un paragraphe et un lien pour une destination.

  • <h1> à <h6> structurent les niveaux de titres ;
  • <p> contient un paragraphe lisible ;
  • <a href="..."> crée un lien vers une autre ressource ;
  • <img alt="..."> associe une image à une description utile.

Une méthode simple pour progresser

Commence par écrire le contenu sans décoration, vérifie la hiérarchie des titres, puis ajoute le CSS et JavaScript seulement lorsque cela améliore l’expérience. Un HTML propre rend les prochaines étapes plus simples.
