Qu'est-ce que Python ?

Python est un langage de programmation interprété, orienté objet et de haut niveau. Il est connu pour sa simplicité et sa lisibilité.

Installation

Pour installer Python, rendez-vous sur le site officiel python.org et téléchargez la dernière version.

Hello World

Le premier programme en Python est simple : print("Hello, World!")

Variables et types

En Python, les variables sont dynamiquement typées. Exemples : x = 5, name = "Alice"

Structures de contrôle

Python utilise l'indentation pour définir les blocs de code. Les structures incluent if, for, while.
