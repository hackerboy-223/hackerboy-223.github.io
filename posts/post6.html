Python est simple à lire, mais assez puissant pour de vrais systèmes.

Ce cours te donne une base propre : types, contrôle du flux, fonctions, collections, erreurs, modules et environnements virtuels.

Niveau · débutantLecture · 40 minPython 3

Dans ce cours

L’indentation n’est pas décorative en Python : elle définit la structure des blocs.

PrérequisAucune expérience requise
ObjectifÉcrire un petit programme structuré
RéférenceDocumentation Python

Objectifs d’apprentissage

  • manipuler les principaux types et opérateurs ;
  • écrire conditions et boucles lisibles ;
  • concevoir des fonctions avec paramètres et valeurs de retour ;
  • choisir entre liste, tuple, dictionnaire et ensemble ;
  • gérer les erreurs avec try/except ;
  • isoler les dépendances d’un projet avec venv.

1. Premier programme

name = "Awa"
print(f"Bonjour {name} !")

Python privilégie une syntaxe lisible. Les chaînes préfixées par f permettent d’insérer facilement des expressions dans du texte.

2. Variables et types

age = 17             # int
price = 12.5         # float
name = "Moussa"      # str
active = True        # bool
nothing = None       # absence de valeur

Python est dynamiquement typé : le type est associé à la valeur plutôt qu’à une déclaration explicite de variable. Cela ne signifie pas que les types sont inexistants.

3. Conditions

score = 14

if score >= 10:
    print("Validé")
elif score >= 8:
    print("Presque")
else:
    print("À retravailler")

L’indentation regroupe les instructions appartenant au même bloc.

4. Boucles

skills = ["HTML", "CSS", "Python"]

for skill in skills:
    print(skill)

attempts = 0
while attempts < 3:
    attempts += 1

Utilise for lorsque tu parcours une collection, et while lorsqu’une répétition dépend d’une condition.

6. Fonctions

def calculate_total(price, quantity=1):
    return price * quantity

total = calculate_total(4500, 3)
print(total)

Une fonction doit idéalement accomplir une responsabilité identifiable. Les paramètres configurent son comportement et return fournit le résultat à l’appelant.

7. Compréhensions : transformer une collection

prices = [5000, 12000, 28000, 45000]
affordable = [price for price in prices if price <= 30000]

Les compréhensions sont puissantes, mais une version trop complexe devient moins lisible qu’une boucle classique. La clarté reste prioritaire.

8. Gérer les erreurs

raw = input("Âge : ")

try:
    age = int(raw)
except ValueError:
    print("Entre un nombre valide.")

Évite les except: trop larges lorsque tu peux cibler une exception précise. Cela empêche de masquer des erreurs inattendues.

9. Modules et imports

# tools.py
def slugify(text):
    return text.lower().replace(" ", "-")

# app.py
from tools import slugify
print(slugify("Mon Projet"))

Les modules permettent de répartir les responsabilités dans plusieurs fichiers plutôt que d’accumuler tout le programme dans un seul script.

10. Environnements virtuels

Deux projets peuvent dépendre de versions différentes d’une bibliothèque. La documentation Python recommande les environnements virtuels pour isoler les dépendances.

python -m venv .venv

Active ensuite l’environnement selon ton système, puis installe uniquement les dépendances nécessaires au projet. Le dossier d’environnement lui-même ne doit généralement pas être versionné.

11. Lire un fichier proprement

with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

Le bloc with garantit la fermeture correcte de la ressource après utilisation.

À retenir

  • Python mise beaucoup sur la lisibilité et l’indentation.
  • Choisir la bonne structure de données simplifie le reste du programme.
  • Les fonctions et modules permettent de maîtriser la complexité.
  • Les environnements virtuels isolent les dépendances entre projets.
